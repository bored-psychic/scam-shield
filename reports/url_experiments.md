## Augmentation for E and F (train only)

Why: the Tranco benign train rows are bare registered domains with no `www.`, no `/` and no path in 100% of rows, so a model can learn how benign URLs are written in this corpus instead of what makes a host risky (shares in the table further down). `augment_benign` adds, for each Tranco benign **train** row, up to three variants: `https://www.<domain>/`, `https://<domain>/`, `http://<domain>`. Variants inherit split train and label benign, source `tranco_aug`, `is_synthetic` True (CLAUDE.md rule 4: never counted as real, never in val / test); they are held in a separate frame, so every val / test table is on the unchanged real rows. `top_tld` is taken from the real train rows only (the variants copy existing TLDs). Parents: 15636 Tranco benign train rows.

| variant | added (all train) | skipped | why skipped | same URL string as an existing urls.csv row | F: same features as the parent row | E: same features as the parent row |
| --- | --- | --- | --- | --- | --- | --- |
| https://www.<domain>/ | 15627 | 9 | 8 registered domain starts with a www label; 1 registered domain of the variant differs from the parent's (parent is a public suffix) | 18 | 0 | 0 |
| https://<domain>/ | 15636 | 0 | - | 3 | 15636 | 0 |

## Limits

- One seed (0), no tuning, one train/val/test split: differences of about 0.005 AUROC or one probe are within noise that this report does not measure.
- The probes are 25 hand-picked strings (18 genuine, 7 fake); 'genuine' are all well-known Indian sites on their own domains, so they say little about unknown sites.
- The augmentation only adds `www.` and a bare `/`. Tranco benign rows still have no path longer than `/`, no query and no subdomain other than `www`, so path-depth features can still learn the source; the deep-link probes and the with / without-a-path table are the check, not a fix.
- Variants that are feature-identical to their parent (table above) re-weight the bare-domain rows instead of adding information; the HGB class weights and the val-chosen threshold move with them. This report does not separate the weight effect from the `www` / `/` information.
- `subdomain` groups mix source and shape (Tranco is all bare domains).
- A is a re-fit on the current file; the deployed model is a different (older) fit, see Basis.
- 12 `urls.csv` rows carry a redirect URL inside the query; `path_features` takes the `://` there for the scheme and misreads them, exactly as `url_head.py`'s full-URL view does. It affects only the path features of D and E for those rows.
- Runtime 150s.
